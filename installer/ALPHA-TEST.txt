PDF EDITOR {{VERSION}} - ALPHA TEST
===============================

Thanks for trying it. This is an early test version: it works, but expect rough edges.

INSTALL
  1. Unzip this folder anywhere.
  2. Run "PDF Editor Setup {{VERSION}}.exe".
     Windows may say "Windows protected your PC" (the file isn't signed yet):
     click "More info", then "Run anyway".
  3. Click Install. No admin rights needed. It appears in the Start menu.
  Remove it any time: Windows Settings > Apps > PDF Editor > Uninstall.

WHAT TO TRY (whatever you normally do with PDFs)
  - Open big drawings and long documents; zoom, scroll, search (Ctrl+F).
  - Mark up: highlights, text boxes (any font, Arabic too), callouts, clouds, stamps.
  - Measure: set the scale, then length / area / count.
  - Pages: rotate, insert, delete, merge files, reduce file size.
  - Edit text, page numbers, watermarks, redaction, OCR on scans.
  - Save, then open the file in another PDF program: everything should look the same.
  - "Find a tool" (Alt+Q) if you can't find something.

REPORTING PROBLEMS
  File > Report a problem: say what you did and what went wrong (a picture of the
  window can go with it). Crashes are noted by themselves.
  Your copy has no shared reports folder, so reports stay on your PC:
  Settings > Help > "Show them" opens the folder - send me those files.

GOOD TO KNOW
  - Everything stays on your PC. Only the AI assistant (AI tab) uses the internet,
    and only with your own key.
  - Saving keeps the previous version in a backups folder (Settings > Open backups folder).
  - The full user guide is README.txt.
